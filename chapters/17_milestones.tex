Milestones structure the development journey into measurable achievements. This chapter outlines six critical milestones from problem definition through final compliance documentation, with the first three completed in Term 1 establishing the proof of concept. We detail the progression from market validation and technical research to security hardening, AI sidecar deployment, and comprehensive system testing.
\end{sectionintro}

The development of zGate is structured around six critical milestones that progressively build the system from foundational research to a production-ready solution. The first three milestones, which have been successfully completed during Term~1, established the architectural core and delivered a functional Proof of Concept (POC). The remaining three milestones focus on security hardening, identity integration, AI sidecar deployments, and comprehensive system validation.

\section{Milestone Roadmap}

\subsection{Milestone 1: Problem Definition \& Market Validation}
\textbf{Status:} Completed \hfill \textbf{Duration:} September 5 -- October 15

This foundational phase established the theoretical framework for zGate by validating the necessity for a granular, identity-based database proxy within the Zero Trust security paradigm.

\subsubsection{Objectives}
\begin{itemize}
    \item Define the scope of the ``Zero Trust Database Access'' problem domain.
    \item Benchmark existing solutions and identify market gaps.
    \item Establish the initial system architecture.
\end{itemize}

\subsubsection{Key Activities}
\begin{itemize}
    \item \textbf{Gap Analysis:} Investigated the limitations of traditional VPNs and existing database proxies such as Hoop.dev and PgBouncer. The analysis revealed critical weaknesses in access granularity and user experience that zGate aims to address.
    \item \textbf{Architecture Design:} Defined the ``Man-in-the-Middle'' architecture required to intercept binary wire protocols for MySQL, PostgreSQL, and MSSQL
    \item \textbf{Requirements Specification:} Finalized the requirement for protocol-agnostic handling and identity provider integration.
    \item \textbf{Feasibility Study:} Researched the technical viability of intercepting binary wire protocols without introducing significant latency overhead.
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item Validated Software Requirements Specification (SRS).
    \item Initial architectural diagrams and system design documents.
\end{itemize}

%-----------------------------------------------------------

\subsection{Milestone 2: Technical Skill Acquisition \& Research}
\textbf{Status:} Completed \hfill \textbf{Duration:} October 16 -- November 15

Following the initial research phase, this milestone was dedicated to equipping the development team with the specialized technical skills and theoretical knowledge required to build a high-performance database proxy.

\subsubsection{Objectives}
\begin{itemize}
    \item Acquire proficiency in the Go programming language.
    \item Understand low-level database communication protocols.
    \item Explore modern observability concepts and standards.
\end{itemize}

\subsubsection{Key Focus Areas}
\begin{itemize}
    \item \textbf{Database Protocol Engineering:} Conducted in-depth study of the binary wire protocols for MySQL, PostgreSQL, and MongoDB. This involved reverse-engineering how databases handle handshakes, authentication sequences, and query transmission at the packet level.
    \item \textbf{Go Language Mastery:} Focused on mastering the Go programming language, with particular emphasis on its concurrency primitives---Goroutines and Channels---which are essential for managing multiple simultaneous network connections efficiently.
    \item \textbf{Observability Research:} Investigated the principles of system observability, including OpenTelemetry standards and eBPF concepts for potential kernel-level tracing in future iterations.
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item Team proficiency in the project's technology stack.
    \item Internal documentation on protocol structures.
    \item Initial Go practice implementations and code samples.
\end{itemize}

%-----------------------------------------------------------

\subsection{Milestone 3: Functional Proof of Concept \& Core Features Delivery}
\textbf{Status:} Completed \hfill \textbf{Duration:} November 16 -- December 15

Originally scoped to focus solely on connection handling, this milestone was strategically expanded to deliver a complete Proof of Concept. The POC encompasses the initial web interface, basic security mechanisms, and internal token management capabilities.

\subsubsection{Objectives}
\begin{itemize}
    \item Validate the full technology stack from the web frontend to database connectivity.
    \item Demonstrate that the proxy can handle traffic, mask sensitive data, and manage internal sessions.
\end{itemize}

\subsubsection{Key Activities}
\begin{itemize}
    \item \textbf{Proxy Core Development:}
    \begin{itemize}
        \item Implemented TCP listeners and connection pooling mechanisms for high-concurrency traffic.
        \item Developed protocol parsers for MySQL, PostgreSQL, and MongoDB packets.
        \item Built the core data forwarding logic with support for bidirectional communication.
        \item Handled CLI errors and established graceful shutdown procedures.
    \end{itemize}
    \item \textbf{Security Logic Implementation:}
    \begin{itemize}
        \item Implemented Data Masking functionality using regex-based redaction for PII.
        \item Built Token Refresh and Revocation mechanisms for session management.
        \item Developed OAuth2-style authentication flows (login, refresh, logout).
        \item Implemented AES encryption for secure storage of credentials.
    \end{itemize}
    \item \textbf{User Interface Development:}
    \begin{itemize}
        \item Developed the Initial Admin Dashboard Web UI to visualize system status.
        \item Built components for managing database accounts and access control roles.
        \item Integrated real-time session and query monitoring capabilities.
    \end{itemize}
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item A working end-to-end Proof of Concept demonstrating core functionality.
    \item Admin dashboard with system visibility and management capabilities.
    \item Functional data masking and token management subsystems.
\end{itemize}

\subsection{Milestone 4: Security Hardening, Identity Integration \& AST Parsing}
\textbf{Status:} $\checkmark$ Completed \hfill \textbf{Duration:} January 1 -- March 14

Brief Description: Harden authentication paths with MFA, PKCE, and OS-native keystores, while transitioning SQL evaluation from basic regex to high-fidelity Abstract Syntax Tree (AST) visitors with multi-level admin controls.

\subsubsection{Objectives}
\begin{itemize}
    \item Architect standard-compliant secure token management lifecycles and isolate gateway client identity using host-native hardware keyrings.
    \item Enforce compile-time query evaluation using AST scanning to block malicious structural SQL injection vectors.
    \item Introduce strict multi-tier administrative permissions for user and server management actions.
\end{itemize}

\subsubsection{Key Activities}
\begin{itemize}
    \item \textbf{Identity Integration:} Explored Keycloak and Auth0 identity providers to design robust Multi-Factor Authentication (MFA) and PKCE workflows.
    \item \textbf{Credential Abstraction:} Integrated OS-native secure credential abstractions including macOS Keychain, Windows Credential Manager, and Linux Secret Service.
    \item \textbf{AST Safety Parsing:} Developed the C\# AST Safety Analysis Visitor and dynamic Schema Masking Visitor inside a dedicated parsing assembly.
    \item \textbf{gRPC Channels:} Built high-speed backend gRPC hosting channels to allow real-time communication between the Go server proxy and the C\# parser.
    \item \textbf{Admin privilege infrastructure:} Designed and implemented the Multi-Level Admin Privilege infrastructure on the backend and Next.js frontend.
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item \textbf{zGate-CLI:} Go-based command line agent fitted with secure OS keyring bindings, GitHub Actions CI pipelines, and OAuth2 device flows.
    \item \textbf{zGate-Tsql-Parser:} Complete C\# repository tracking token normalization visitors, safety rules, and gRPC server bootstrappers.
    \item \textbf{zGate-WebUI:} Multi-tier admin workspaces, live system query telemetry tables, role privilege assigner dialogs, and SSO/PKCE screens.
\end{itemize}

%-----------------------------------------------------------

\subsection{Milestone 5: AI Sidecar, Observability \& Production Deployment}
\textbf{Status:} $\checkmark$ Completed \hfill \textbf{Duration:} March 15 -- May 24

Brief Description: Deploy an isolated Python-based machine learning sidecar for anomaly detection and data masking, configure Prometheus/Grafana observability, integrate HashiCorp Vault, and launch containerized Next.js/Caddy environments.

\subsubsection{Objectives}
\begin{itemize}
    \item Intercept database logs through machine learning models to identify abnormal runtime query patterns.
    \item Incorporate automated telemetry systems to monitor core server health metrics.
    \item Eliminate plaintext configuration profiles by seeding gateway microservices through encrypted secret vaults and orchestration layers.
\end{itemize}

\subsubsection{Key Activities}
\begin{itemize}
    \item \textbf{Machine Learning Models:} Built PyTorch Deep Denoising Autoencoders, supervised XGBoost Classifiers, and Multi-Model Stacker scoring pipelines.
    \item \textbf{PII Redaction Engine:} Engineered AI-based dynamic column classifications, heuristic regex policies, and masking rules to redact PII from database responses.
    \item \textbf{Observability Integration:} Configured the centralized Prometheus/Grafana Telemetry \& Observability stack for the server engine to track live connection latency.
    \item \textbf{Vault and Orchestration:} Integrated HashiCorp Vault infrastructure and engineered deployment pipelines using Docker Compose orchestrations with Caddy Edge Reverse Proxies.
    \item \textbf{WebUI Hash Refactoring:} Refactored WebUI data display layers to strip predictable database IDs, replacing them with custom encrypted GUID structures.
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item \textbf{zGate-AI:} Python service sidecar featuring ML classification pipelines, fingerprint trackers, and an interactive AI chat assistant.
    \item \textbf{zGate-Deploy:} Production blueprints detailing development and deployment branch environments, custom Caddy rulesets, and Vault setups.
    \item \textbf{zGate-WebUI:} Production-ready release built with serverless routing rules, custom onboarding walkthrough tours, filtered histories, and Stripe billing engine checkouts.
\end{itemize}

\subsection{Milestone 6: Comprehensive System Testing \& Compliance Documentation}
\textbf{Status:} $\checkmark$ Completed \hfill \textbf{Duration:} June 1 -- June 17

Brief Description: Formulating formal system threat models, optimizing test suite execution, compiling project coverage matrices, and finalizing graduation project attestation documentation.

\subsubsection{Objectives}
\begin{itemize}
    \item Evaluate full cross-workspace component reliability through rigorous unit and integration test strategies.
    \item Draft centralized threat evaluation models to document edge infrastructure security and resilience.
\end{itemize}

\subsubsection{Key Activities}
\begin{itemize}
    \item \textbf{Testing Workflows:} Formulated extensive unit and integration testing workflows across frontend views and proxy layers.
    \item \textbf{Code Coverage Analysis:} Verified code execution coverage reports to target unhandled application error boundaries.
    \item \textbf{Threat Modeling:} Drafted the official graduation project system Threat Model, specifically analyzing Out-Of-Memory (OOM) vectors and Denial of Service (DoS) vulnerability resilience.
    \item \textbf{Technical Compilation:} Compiled team technical documentation sections, timeline logs, and contribution indexes for final review.
\end{itemize}

\subsubsection{Deliverables}
\begin{itemize}
    \item \textbf{Documentation:} Completed graduation technical documentation manual featuring Threat Models, structural blueprints, and compliance attestations.
    \item \textbf{Test Harness:} Complete automated test suites providing robust code coverage execution across all active repositories.
